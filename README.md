# *BVR - Balance and Variety Rework*
## *What this is:*
## This rebalance project aims to push Nuclear Option's gameplay more towards a realistic simulator experience while still honouring ShockFront's vision. 
So the changes will very rarely change a value by more than 50%.

## *Its main design principle is customisation.*
Any change the mod introduces can be toggled and all values can be tweaked. (allows sandbox style play)
When playing multiplayer, it has a hash system which hopefully means you can only see each-other's servers when you have the same config.
It has a few tools to help find config differences.

## *What this does currently:*
### *General Missile Changes:*
- Slightly buffs IR missiles but also gives you more flares. (base values are based on a poll I made in offtopic a while ago)

### *Chicane Changes:*
- Gives the Chicane Flak shells on the 30mm. (they have a very small splash radius, but they can intercept munitions. This gives the Chicane a new role as a flying AFV6AA)
- Gives the Chicane inner bays a x14 Lynchpin option.
- (Disabled by default) Optionally gives the Chicane either 2 or 4 Scythes total by using the inner wing pylons.

### *Medusa Changes:*
- Buffs the Medusa's laser by lowering its energy consumption. (It now has a new role in the form of a decent-ish PD unit)
